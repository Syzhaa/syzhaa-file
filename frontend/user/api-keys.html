menu_book Cara Menggunakan API

Base URL: https://ambilfile.web.id — semua request wajib menyertakan header Authorization: Bearer API_KEY_KAMU

POST/api/v1/room/create

Buat room baru. Body JSON: {"expiry_minutes": 60} (10–10080 menit, default 60). Response berisi room_id, pin, dan expires_at.

GET/api/v1/room/{room_id}/link

Ambil link berbagi room: room_link, pin_link, dan pin.

GET/api/v1/room/{room_id}/files

Daftar file dalam room: nama, ukuran, jumlah download, dan download_url tiap file.

GET/api/v1/room/{room_id}/download-all

Download semua file dalam room sebagai satu file ZIP.

Contoh — curl

curl -X POST https://ambilfile.web.id/api/v1/room/create \
  -H "Authorization: Bearer API_KEY_KAMU" \
  -H "Content-Type: application/json" \
  -d '{"expiry_minutes": 1440}'

Contoh — JavaScript

const res = await fetch('https://ambilfile.web.id/api/v1/room/create', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer API_KEY_KAMU',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ expiry_minutes: 1440 })
});
const data = await res.json();
console.log(data.room_id, data.pin);
